# HMI آموزشی راه‌اندازی الکترولایزر

یک رابط آموزشی فارسی و تعاملی برای توالی راه‌اندازی تک‌الکترولایزر ممبرانی `41EL08101A` با ۱۶۳ المان.

![آیکون HMI](assets/electrolyzer-hmi-icon.jpg)

## قابلیت‌ها

- نمایش شماتیک فرایند، جزئیات عملیاتی و گام‌های راه‌اندازی
- حالت روز و شب
- نمایش متحرک جریان‌های گاز با شدت متناسب با بار الکترولایزر
- نمایش وضعیت ولوها و مسیرهای گاز در هر گام
- جدول ۶-۶ دبی آب‌نمک و کاستیک تا بار نامی
- پیش‌نیازهای مستندشده برای دما، غلظت آب‌نمک و پلاریزاسیون

## اجرا

این پروژه وابستگی و فرایند build ندارد. فایل `index.html` را با یک مرورگر باز کنید.

## انتشار با GitHub Pages

1. مخزن را به GitHub ارسال کنید.
2. از بخش **Settings → Pages**، گزینهٔ **Deploy from a branch** را انتخاب کنید.
3. شاخهٔ `main` و پوشهٔ `/(root)` را برای انتشار برگزینید.
4. پس از انتشار، GitHub Pages همین فایل `index.html` را به‌عنوان صفحهٔ اصلی نمایش می‌دهد.

## یادداشت ایمنی

این HMI صرفاً آموزشی و تصمیم‌یار است و هیچ فرمانی به تجهیزات، FCS، SIS، رکتیفایر یا ولوها ارسال نمی‌کند. عملیات واقعی فقط باید بر پایهٔ رویه‌های مصوب سایت و تأیید اپراتور مجاز انجام شود.
